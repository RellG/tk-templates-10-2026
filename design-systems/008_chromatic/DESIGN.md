# Chromatic

> One language. Every color of possibility.

**Theme:** dark

## Origin
Original TKTechnology design direction, October 2026. Fictional demo brand. No third-party site was scraped for this collection.

## Layout
Oversized display type at 120px with full-bleed hero. Include tabs showcase pricing. Use 2px card corners, generous whitespace, and a responsive mobile stack.

| Ink | `#fff1ff` | `--color-fg` | foreground |
