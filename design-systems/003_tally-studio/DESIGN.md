# Tally Studio

> Big questions. Beautifully simple answers.

**Theme:** light

## Origin
Original TKTechnology design direction, October 2026. Fictional demo brand. No third-party site was scraped for this collection.

## Layout
Oversized display type at 120px with full-bleed hero. Include stats showcase quotes. Use 24px card corners, generous whitespace, and a responsive mobile stack.
